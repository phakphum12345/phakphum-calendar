# DISKPATH

> Automatically generated repository disk-path manifest.
> Do not edit this file manually.

## Purpose

This document is generated from the actual repository tree.

It records:

- repository-relative file paths
- file size in bytes
- SHA-256 for each file

This manifest is documentation/evidence only. It does not define
runtime authorization, application behavior, or deployment policy.

## Generation

The GitHub Actions workflow:

`.github/workflows/generate-diskpath-md.yml`

runs:

- manually through `workflow_dispatch`
- automatically when relevant files are pushed to `main`

`DISKPATH.md` is excluded from its own trigger to prevent a
self-trigger loop.

The generated manifest is committed only when its content changes.
