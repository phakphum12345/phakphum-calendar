# Project completion and live audit

This folder is the current operational source of truth for the repository completion effort. It is updated from live GitHub refs, exact-head CI, review state and acceptance evidence.

- [Project completion master plan](PROJECT_COMPLETION_MASTER_PLAN.md) — current baseline, scope and critical path.
- [Work package status](WORK_PACKAGE_STATUS.md) — implementation/test/review/operational state by package.
- [PR dependency map](PR_DEPENDENCY_MAP.md) — current PR stacking and safe delivery order.
- [Acceptance matrix](ACCEPTANCE_MATRIX.md) — testable exit criteria and evidence still required.
- [Known limitations](KNOWN_LIMITATIONS.md) — unverified behavior and external blockers.

Do not treat historical dated plans or PR descriptions as current state. Refresh the live GitHub baseline before changing any status. A green CI workflow does not imply review, merge, operational acceptance or deployment.
