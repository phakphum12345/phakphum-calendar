# Zero-cost operations and observability

Reuse existing hosting, database and automation. Prefer deterministic local capability when remote services are absent. Set quotas, payload limits, timeouts and retention before remote AI. Do not create paid resources or upgrade plans without explicit approval.

Track readiness, deployed SHA, API health, auth failures, provider availability, rate limits and integration errors without logging secrets or private roster content. Optional provider failure must not disable core workflows. Maintain setup, deploy, rollback, backup/restore, outage, credential rotation and incident runbooks.
