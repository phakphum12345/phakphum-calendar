# End-to-end test strategy

Layers: domain unit; application/authorization; infrastructure contract; UI/widget; cross-platform integration; deployed E2E with normal accounts.

Critical journeys: Personal without organization; least-privilege organization member; Hybrid no-double-count; rule conflicts/missing configuration; roster provenance; public Google identity with incremental scopes; AI offline/live/unavailable/privacy/confirmation; clean install/upgrade/sign-out/recovery.

Evidence records environment, exact source SHA, fixture type, platform and result. Mocks cannot prove external live readiness.
