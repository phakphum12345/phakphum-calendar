ตั้งค่า Google Workspace และ OAuth

คู่มือสำหรับเชื่อมต่อ Phakphum Calendar กับ Google Sheets, Google Drive และ Google Calendar

1. เตรียม Google Cloud project

  1. เปิด Google Cloud Console แล้วเลือกหรือสร้างโปรเจกต์ที่คุณควบคุม
  2. เปิดใช้งาน Google Drive API, Google Sheets API และ Google Calendar API
  3. เปิด Google People API เฉพาะเมื่อจะใช้การนำเข้าหรือส่งออกรายชื่อผู้ติดต่อ
  4. ตั้งค่า OAuth consent screen และเพิ่มบัญชีทดสอบ หากแอปยังอยู่ในสถานะ Testing

2. สร้าง OAuth Client สำหรับเว็บ

  1. ไปที่ APIs & Services → Credentials
  2. เลือก Create Credentials → OAuth client ID แล้วเลือกชนิด Web application
  3. เพิ่ม Authorized JavaScript origins สำหรับที่อยู่ที่ใช้งานจริง ตัวอย่างเช่น https://phakphum12345.github.io
  4. หากรันเว็บในเครื่อง ให้เพิ่ม origin ที่ตรงกับพอร์ตจริง เช่น http://localhost:8080
  5. คัดลอกค่า Client ID ที่ลงท้ายด้วย .apps.googleusercontent.com ไปตั้งค่าในขั้นตอน build/configuration ของแอป

สำคัญ: ใช้ Client ID เท่านั้น ห้ามใส่ Client Secret, access token, refresh token หรือ private key ลงในหน้าเว็บ, source control หรือข้อความสาธารณะ

3. ตรวจสอบก่อนเชื่อมต่อ

  • ตรวจว่า origin ในเบราว์เซอร์ตรงกับ Authorized JavaScript origins ทุกตัวอักษร รวมถึง protocol และ port
  • ตรวจว่า OAuth consent screen อนุญาตบัญชี Google ที่ใช้ทดสอบ
  • อนุญาตเฉพาะสิทธิ์ที่แอปแสดงและจำเป็นต่อการทำงาน
  • ก่อนบันทึกหรือซิงก์ตารางเวร ให้ตรวจตัวอย่างข้อมูลและยืนยันรายการที่ต้องการเสมอ

4. แก้ปัญหาเบื้องต้น

  • origin_mismatch: เพิ่ม origin ที่ตรงกับ URL จริงใน OAuth client แล้วบันทึกการตั้งค่า
  • หน้าต่างเข้าสู่ระบบปิดทันที: ตรวจ Console ของเบราว์เซอร์, Client ID, consent screen และการตั้งค่า OAuth ของ build ที่ deploy อยู่
  • ยังซิงก์ไม่ได้: ตรวจ API ที่เปิดใช้และสิทธิ์ที่อนุญาต แล้วลองเชื่อมต่อใหม่

ดูรายละเอียดเพิ่มเติมได้ที่ Google Cloud and OAuth Setup และ คู่มือติดตั้งและใช้งาน

คู่มือนี้ให้แนวทางการตั้งค่าเท่านั้น ไม่ได้ยืนยันว่า OAuth หรือการซิงก์ของบัญชีใดทำงานสำเร็จแล้ว
