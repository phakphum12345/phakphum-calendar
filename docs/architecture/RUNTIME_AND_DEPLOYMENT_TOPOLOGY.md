# Runtime and deployment topology

Inventory Flutter clients, backend routes, persistence, Google OAuth/API integrations, optional AI/retrieval adapters, Pages and platform release artifacts.

For development, CI, staging and production record origin, API base URL, redirect URIs, secrets source, storage, logging, quotas and owner. Prefer existing infrastructure and deterministic local behavior. No paid provider/hosting/database/search component is implied. Build success is not deployment proof: record deployed artifact, exact SHA, environment, URL, smoke test and rollback.
